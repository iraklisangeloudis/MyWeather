# Third-party artwork

Weather artwork: [Meteocons](https://meteocons.com/) by Bas Milius, MIT licensed.

Source: `@meteocons/lottie` version 0.1.0, Flat style, from the npm registry.
The selected JSON animations are bundled locally under `app/src/main/res/raw`.
Near-white cloud fills were adjusted for contrast with the app surfaces; shapes and motion are unchanged.
The main current-weather icon animates; forecast and detail icons display a static frame.

The original copyright and complete MIT license ship in `app/src/main/assets/licenses/meteocons.txt`.

Animation rendering: [Lottie Android](https://github.com/airbnb/lottie-android) 6.6.7, Airbnb, Apache License 2.0. Its license ships in `app/src/main/assets/licenses/lottie.txt`.
